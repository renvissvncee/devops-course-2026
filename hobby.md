# Мой пет-проект
Идея: цифровой агрегатор кофеен
Стек: Go, JS, React, PostgreSQL
Цель: научиться работать с современными технологиями и создать полезный сервис для любителей кофе.
Срок реализации: 3 месяца
Ожидания: получить опыт в разработке веб-приложений, улучшить навыки работы с базами данных и фронтенд-разработкой, а также создать продукт, который может быть полезен для сообщества.
